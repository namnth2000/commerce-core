# Design

## Shared direction

```text
Minimal
Calm
Functional
Light
Readable
```

Prefer usability over visual novelty.

- light background and neutral surfaces
- strong text readability
- subtle borders
- small to medium radius
- little or no shadow
- short functional motion only
- simplify layout on mobile instead of shrinking everything
- use one consistent outline icon style if icons are introduced
- do not use emoji as functional icons

## Admin Portal

The Admin Portal should feel like a lightweight publishing tool, not a developer console.

Use merchant language:

- Product
- Save draft
- Preview
- Publish
- Image optimization

Avoid exposing:

- branch
- commit
- merge
- SHA
- repository internals

The v0.1 screen should make the main job obvious: select a product, edit it, optimize an image, then save.

## Demo storefront

The first storefront sells playful technology and desk decor for office workers.

Direction:

- clean office aesthetic
- slightly playful product imagery
- generous but not excessive spacing
- one cool accent color
- product photography/illustration is the visual focus
- avoid large marketing hero sections
- prioritize product browsing and cart behavior

The storefront is an example, not the permanent visual identity for all future stores.
